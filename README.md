# 🌳 Multiple Pathways and Drivers of Woody Vegetation Transformation in the Gran Chaco

## Overview

This repository contains the spatial datasets, maps, and scripts associated with the study *“Multiple Pathways and Drivers of Woody Vegetation Transformation in the Gran Chaco.”* 
The materials document the modeling and mapping of five woody vegetation transformation pathways across the Gran Chaco, including transition probability maps and an integrated representation 
of potential land-cover changes.
